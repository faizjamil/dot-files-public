# General

* Compositor Options:

  * Disable compositing for full-screen windows: `on`

* Miscellaneous Options
  * Enable timer when logging out or shutting down: `on`
  * Timer delay (seconds): `60`

* Memory limit
  * Restart Cinnamon when it uses too much memory: `on`
  * Memory limit (MB): `2048`
  * Check frequency (seconds): `300`
