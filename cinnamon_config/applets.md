# Applets

The following are both the list of installed applets and enabled settings for each applet, written as child lists

* Calendar
  * Show calendar events: `on`
  * Show calendar: `Super+C`
* Grouped window list
  * General
    * Behavior
      * Group windows by application: `on`
      * Mouse wheel scroll action: `None`
      * Left click action: `None`
      * Middle click action: `Close last focused window in group`
      * Show windows from other monitors: `Only from monitors without a window list`
    * Hot Keys
      * Global hotkey for cycling through thumbnail menus: `unassigned`
      * Global hotkey to show the order of apps: `Super+<backtick>`
      * Duration of the apps order display on hotkey press (milliseconds): `2500`
      * Enable `Super+<number>` shortcut to switch/open apps: `on`
  * Panel
    * Application Buttons
      * Button label: `None`
      * Launcher animation: `Scale`
      * Show window count badges: `on`
      * Show notification badges: `on`
      * Enable app button dragging: `on`
  * Thumbnails
    * Thumbnails
      * Show thumbnails: `on`
      * Highlight the thumbnail of the last focused window: `on`
      * Delay before showing thumbnails: `250 ms`
      * Thumbnail size: `Medium`
    * Hover Peek
      * Show the window when hovering its thumbnail: `on`
      * Window fade-in time: `300 ms`
      * Window fade-out time: `None`
      * Window opacity (percent): `100`
    * Context Menu
      * Show recent items: `on`
      * Apply the monitor move option to all windows: `on`
* Menu
  * Content
    * Content
      * Sidebar: `on`
      * Avatar: `on`
      * Favorites: `on`
    * Import `menu applet.json` if any apps are missing
  * Appearance
    * Options
      * Position of the search bar: `At the bottom`
      * Position of the system buttons: `In the sidebar`
      * Show application descriptions: `on`
      * Use symbolic icons for categories: `on`
      * Categories icon size (px): `22`
      * Applications icon size (px): `22`
      * Sidebar icon size (px): `24`
      * Maximum sidebar width (px): `180`
  * Behavior
    * Menu
      * Change categories on hover: `on`
      * Enable autoscrolling in application list: `on`
    * Panel
      * Keyboard shortcut to open and close the menu: `Left Super` (`Super L`) and `Right Super` (`Super R`)
* Network Manager
* Notifications
  * Behavior
    * Ignore transient notifications: `on`
  * Display
    * Show the number of notifications: `on`
  * Keyboard shortcuts
    * Show notifications: `Super+N`
    * Clear notifications: `Shift+Super+C`
  * Notification settings:
    * Enable notifications: `on`
    * Monitor to use for displaying notifications: `Primary monitor`
    * Notification duration (seconds): `4`
  * Media keys OSD
    * Show media keys OSD: `on`
* Power Manager
* Printers
* Removable Drives
* Sound
  * Menu
    * Control Players: `on`
    * Show menu: `Shift+Super+S`
  * Panel
    * Action on middle click: `Toggle Mute`
    * Action on shift+middle click: `Toggle Mute Input`
    * Hide system tray icons for compatible players: `on`
  * Tooltip
    * Show volume in tooltip: `on`
* System Tray
* XApp Status Applet
