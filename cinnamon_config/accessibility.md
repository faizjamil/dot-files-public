# Accessibility

## Visual

### Visual Aids

* High contrast: `off`
* Large text: `on`
* Screen reader: `off`

### Screen Zoom

* Enable zoom: `on`
* Magnification: `1.0`
* Mouse wheel modifier: `<Alt>` (should be fine when set to `Disabled`)

* Scroll at screen edges: `off`
* Mouse tracking mode: `Cursor moves with contents`
* Lens mode: `off`
* Screen mode: `Full screen`

## Everything else set to `off`
